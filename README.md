# HaloQuest-Extended
An extended version of HaloQuest Dataset, including additional labels that indicates three levels of granularity, each capturing progressively finer details of the
image content. These labels are referred as subject categories which is derived from HaloQuest's themes. 

* L1: Corresponds to the level 1 subject category, when the images’ main interest directly aligns with the provided subject categories.
* L2: Corresponds to the level 2 subject category, when the image contains that object but is not primarily centered on it, alternative interests.
* L3: Corresponds to the level 3 subject category, background objects, incomplete or very small objects in the image
